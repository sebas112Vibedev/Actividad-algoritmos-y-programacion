# Sistema de Gestión de Estudiantes (SGE) básico

Programa de consola hecho en Java para la actividad de estructuras de control.
Permite:

1. Agregar estudiantes (ID, nombre, edad y nota)
2. Mostrar la lista completa con el total, el promedio y los aprobados
3. Mostrar la lista en orden inverso
4. Buscar un estudiante por su ID
5. Salir del sistema

Los datos se guardan en arreglos de máximo 50 estudiantes, así que se borran cuando se cierra el programa.

## Cómo ejecutarlo

Se necesita tener instalado el JDK (Java). En la terminal, dentro de esta carpeta:

```
javac SistemaGestionEstudiantes.java
java SistemaGestionEstudiantes
```
